# PA-Carb MIC Interpreter

Step 2 of the PA-Carb IPM/MEM predictability workflow.

Upload the single-sample or batch `feature_matrix.csv` generated by the companion PA-Carb Feature Extractor Space. This interpreter checks that the matrix contains the manuscript-schema 455 model features and then applies the locked public-only IPM/MEM model.

Prediction is blocked if required model features are missing. Raw FASTA files should be processed by the Feature Extractor first.

This tool is research-use only and is not a validated clinical AST system.
